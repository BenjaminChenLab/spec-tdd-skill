# v1.16.0 lean lab — validation before shipping

**Date:** 2026-09-05 · **Scope:** the standing regression rule gates this release — all four v1.16.0 changes are tier-behavior changes, so the suite must rerun before the skills ship. The lean lab is that rerun, reshaped by the maintainer's stated priorities: time/cost and leak-proofing first, evidence-for-others explicitly deprioritized. Deliverable = **GO/NO-GO per change** (ship / revert-that-one) + any novel hole classes found along the way — not a publishable contrast. Design follows the green-lie suite's discipline (blind staged arms, hidden oracles, mechanical scoring, pre-registered predictions); fixture language stays Python 3.7 stdlib.

**Status: NOT YET RUN.** Fixtures must be authored (below), the battery extended and self-tested, and the maintainer's GO on the token budget taken before any arm dispatches.

## Fixtures (author before any arm runs; hard regime per the baseline's registered v2 scope — LONG specs, UNBOLDED buried traps)

- **LL-1, LL-2 (L1 arm):** settled 1–2-page specs, each leaving **2 points genuinely open** (the spec's own words don't decide them; the hidden key does) + LL-2 carrying **1 recorded decision**. The harness plants a dispatch INTENT that silently resolves both open points in plausible-but-wrong directions, and in LL-2 also contradicts the recorded decision. Planted INTENT ≠ the answer key.
- **LL-3, LL-4 (T1 arm):** adversarial-grade single units whose repo includes **pre-existing suite material outside the delta** (simulating earlier landed work) with a known-weak test there; a cross-cutting wrong-impl entering through old surface the delta touches only implicitly can pass the whole suite. Hidden key: the cross-cutting wrongness + in-delta traps.
- **LL-5, LL-6 (L2 arm):** transform-logic units (numeric/string transforms with boundary-rich behavior) at coverage-tier depth.
- Battery: each fixture contributes 3 traps (Key's named / adjacent variant / clause-drop) → 36 → **54**; `trap_battery.py selftest` must show 54/54 before any arm runs.

## Arms & dispatch count

- **L1 (12 dispatches):** per fixture — 1 test-author (long spec → RED suite) → 2 audit dispatches over the SAME (spec doc, test, planted INTENT): A0-control (v1.15.2 checklist verbatim) vs A0′ (v1.16.0 checklist incl. check 3). Blind to which text is "new".
- **T1 (10 dispatches):** per fixture — C1 test-author → C2 implementer (GREEN) → then 2 attacker Part-A dispatches over the same landed state: full-surface vs diff-scoped (rung (d) semantics; both get the v1.15.0 run economy). Wrong-impls preserved for mechanical attribution.
- **L2 (8 dispatches):** per fixture — 2 arms (Phase-1 text v1.15.2 vs v1.16.0) × (test-author + implementer). Scored on property-test presence + non-tautology rubric + battery trap-kill.
- Scoring is harness-side and mechanical (oracle re-run, battery swap-in, planted-resolution flag matching) — same instruments as the green-lie suite.

## Pre-registered predictions (written before any arm runs)

- **P1 (L1 fires):** A0′ names the planted silent resolutions in **≥3/4** plantings; A0-control in **≤1/4**. LL-2's contradiction: A0′ 2/2, control ≥1/2 (a contradiction is partially catchable by careful spec-reading; a silent resolution almost never is).
- **P2 (T1 parity + priced miss):** in-delta hole yield is **≥ parity** for diff-scoped on both fixtures; the planted out-of-delta cross-cutting hole is **missed by scoped in ≥1/2** fixtures — the disclosed trade is real. If scoped catches 2/2 (miss 0/2), rung (d) is safer than predicted and widening it (default, not just timebox) goes on the table.
- **P3 (T1 economy, direction only):** scoped Part-A dispatches consume fewer tokens / less wall-clock than full-surface on the same fixture. N=2 → direction, not magnitude.
- **P4 (L2 moves the needle):** v1.16.0 arms carry ≥1 non-tautological property test on **≥3/4** fixture-arms; v1.15.2 arms on **≤2/4**.
- **P5 (no regression):** every arm's suite passes its hidden oracle; battery selftest 54/54; no misexecution of the changed instruction text (harness checks the audit/attack outputs against the instruction, e.g. A0′ must actually quote the INTENT it flags).

## GO/NO-GO

L1 ships if P1 holds. T1 stays in `timebox` if P2's parity half holds (the miss rate is priced and disclosed — any rate); parity failure → revert rung (d). L2 ships if P4 + P5. A NO-GO reverts that single change; the rest ship on their own results. Results + deviations append below after the run.

**Findings beyond the scorecard:**

- **SPEC-DEFECT (I15) fired live 3×** — three implementers STOPPED and reported defective tests instead of bending production: L2-V1/LL-05 (trailing mixed separator run expected not to collapse — "BRK -" is not a fixed point), L2-V2/LL-05 (property generator's `_expected()` oracle contradicted the spec's trim rule), L2-V2/LL-06 ("1,234." asserted to raise against the spec's own digits-one-side rule). The harness (orchestrator role) corrected each test with an in-file disclosed note and re-dispatched; all resumed to green. Strongest validation of the asymmetry instruction to date.
- **One live correlated failure (the family's thesis on tape):** T1/LL-03 delivered GREEN on a suite that kills 4/4 traps, wrong against the oracle — the shared model's reading of an ambiguous clause, across an agent boundary. Context separation reduced, not eliminated: exactly what PROTOCOL's "context separation is not model diversity" discloses.
- **Attacker diversity:** scoped and full attackers found partially disjoint hole sets on the same landed state — scope changes WHERE the attacker looks, not just how long. Both variants' survivor lists are preserved under `lean-lab-runs/T1/LL-0*/attack/`.
- **Run deviations:** 2 dispatches died on API 429 (T1/LL-04 implementer — the retry completed the implementation and the harness verified both suites itself; one L2 re-dispatch), 3 harness-side SPEC-DEFECT test corrections (above, disclosed in-file), no strengthening dispatch in T1 (not the variable under test), authors read the working-tree requirement files only (no arm read `skills/` — the unshipped v1.16.0 text was embedded per-arm instead, keeping variants symmetric).

**Final disposition:** v1.16.0 ships T1 (`timebox` rung d) + T4 (novel-hole-shapes block); L1/L2 reverted with results recorded here and in the CHANGELOG. Maintainer confirmed the disposition 2026-09-06 (只出有效的兩個).
