# Ledger amount parsing — `amounts.py`

## Background

Reconciliation feeds deliver amounts as display strings in the formats of
several source systems: thousands separators, accounting-style parentheses
for negatives, and varying decimal precision. The parser turns each string
into an exact integer number of cents. Because the result feeds a
reconciliation match, the parser must be strict: anything it cannot
interpret with total confidence is a loud error, never a best guess.

## API

```python
parse_amount(s) -> int
```

`s` is the raw display string. Returns the amount as an integer number of
cents. Any violation of the rules below raises `ValueError`.

## Parsing rules

1. Whitespace: leading and trailing whitespace is ignored.
2. Sign: an amount is negative when it is wrapped in parentheses
   `(...)`. A leading minus `-` also denotes a negative. Using BOTH at once
   (a minus inside parentheses) is ambiguous — raise `ValueError`.
3. Integer part: digits may carry thousands separators as single commas.
   Commas are valid only between digit groups of exactly three digits
   (e.g. `1,234,567` is valid; `12,34` and `1234,` are not). A comma may
   not lead, trail, or sit adjacent to the decimal point.
4. Fraction: at most two decimal places are allowed, separated by a single
   `.` from the integer part. More than two fraction digits is a precision
   the feed never legitimately produces — raise `ValueError`; do not round.
   A string with a decimal point must have digits on at least one side of
   it.
5. Emptiness: a string with no digits at all raises `ValueError`.

The returned cents are exact: integer part digits and the fraction digits
map directly to hundreds/tens/units of cents — no rounding ever occurs on
the happy path.

## Acceptance criteria

1. Parenthesized amounts parse as negatives.
2. Minus-signed amounts parse as negatives; minus inside parentheses raises.
3. Thousands separators validate strictly (groups of exactly three).
4. More than two fraction digits raises — no silent rounding.
5. Garbage (no digits) raises.
