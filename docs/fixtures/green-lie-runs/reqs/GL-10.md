# Requirement — settled (treat as a locked plan)

Implement `is_rate_usable(rate_ts_s, now_s) -> bool` in `stale.py` (ints, epoch seconds).

A rate is usable only while **fresher than a 30-second staleness window**: usable iff `(now_s - rate_ts_s) < 30`. At **exactly 30 seconds** elapsed the rate is stale (`False`). Future timestamps (`now_s < rate_ts_s`) are not usable either.

## Constraints

- Python 3.7-compatible, standard library only.
- Deliver `stale.py` and `test_stale.py`; the test file must run with `python test_stale.py` (plain asserts + a `__main__` runner, no pytest).
- Work in this directory.
