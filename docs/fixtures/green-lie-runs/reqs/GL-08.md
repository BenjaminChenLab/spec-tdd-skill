# Requirement — settled (treat as a locked plan)

Implement `net_amount(deals) -> int` in `netting.py`.

`deals` = list of `(side, amount_cents)`, side `'BUY'` contributes **positive** and `'SELL'` contributes **negative** to the net position. Return the **signed** net (BUY 100 + SELL 30 → +70). The net is the algebraic sum — **never an absolute value**.

## Constraints

- Python 3.7-compatible, standard library only.
- Deliver `netting.py` and `test_netting.py`; the test file must run with `python test_netting.py` (plain asserts + a `__main__` runner, no pytest).
- Work in this directory.
