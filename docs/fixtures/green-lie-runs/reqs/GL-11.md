# Requirement — settled (treat as a locked plan)

Implement `retry_delays(base_s, max_s, retries) -> list` in `backoff.py`.

The delay **before retry k** (k = 1..retries) is `base_s * 2**(k-1)`, **capped at `max_s`** (base 2, cap 5, 3 retries → `[2.0, 4.0, 5.0]` — the third would be 8 but is capped). `retries = 0` → `[]`.

## Constraints

- Python 3.7-compatible, standard library only.
- Deliver `backoff.py` and `test_backoff.py`; the test file must run with `python test_backoff.py` (plain asserts + a `__main__` runner, no pytest).
- Work in this directory.
