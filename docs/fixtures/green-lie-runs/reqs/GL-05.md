# Requirement — settled (treat as a locked plan)

Implement `overlaps(a_start, a_end, b_start, b_end) -> bool` in `intervals.py` (ints = epoch seconds).

Intervals are half-open `[start, end)`. Two intervals overlap **only when they share a strictly positive duration** — back-to-back intervals (one ending exactly when the next starts) do **not** overlap.

## Constraints

- Python 3.7-compatible, standard library only.
- Deliver `intervals.py` and `test_intervals.py`; the test file must run with `python test_intervals.py` (plain asserts + a `__main__` runner, no pytest).
- Work in this directory.
