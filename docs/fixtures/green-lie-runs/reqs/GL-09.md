# Requirement — settled (treat as a locked plan)

Implement `allocate(amount_cents, caps) -> (list[int], int)` in `allocate.py` (`caps` = list of per-slot caps, filled in order).

Never exceed a cap; never exceed the requested amount; return the **unallocated remainder** as the second element. A **negative amount is invalid: raise `ValueError`** and allocate nothing. Empty or all-zero caps with a positive amount → allocate nothing, remainder = full amount.

## Constraints

- Python 3.7-compatible, standard library only.
- Deliver `allocate.py` and `test_allocate.py`; the test file must run with `python test_allocate.py` (plain asserts + a `__main__` runner, no pytest).
- Work in this directory.
