# Requirement — settled (treat as a locked plan)

Implement `can_approve(maker_user, checker_user, change) -> bool` in `makercheck.py`.

A change may be approved only by a user **different from its maker** — the maker can **never** approve their own change, **with no exceptions for any role** (an administrator who is also the maker is still blocked). `change` is opaque (ignored). Usernames are case-sensitive (`'Alice'` ≠ `'alice'`).

## Constraints

- Python 3.7-compatible, standard library only.
- Deliver `makercheck.py` and `test_makercheck.py`; the test file must run with `python test_makercheck.py` (plain asserts + a `__main__` runner, no pytest).
- Work in this directory.
